Política de
privacidade.

Versão preparada para a nova base técnica. Deve ser revisada com os serviços efetivamente conectados antes da publicação.

Dados tratados pelo site

As ferramentas de acordes e afinação funcionam localmente no navegador e não exigem cadastro. Esta versão do projeto não inclui um formulário próprio de coleta de dados nem identificadores de ferramentas de analytics.

Links e serviços de terceiros

O site contém links para serviços como Hotmart, WhatsApp, Instagram e YouTube. Ao acessar esses serviços, o tratamento de dados passa a seguir as políticas de cada plataforma.

Medição de uso

A interface está preparada para registrar eventos anônimos de navegação, como abertura do dicionário, clique no curso e entrada na comunidade. Nenhum provedor é ativado até que um identificador válido e uma política de consentimento sejam configurados.

Cookies

Esta implementação não cria cookies próprios. Serviços externos podem utilizar cookies quando o usuário abre suas páginas.

Contato

Para assuntos relacionados a privacidade, utilize os canais oficiais de contato. Antes da publicação, deve ser informado aqui um endereço específico para solicitações de titulares.
